# Лабораторная работа №3  

В данной лабораторной работе нужно было применить технологию MPI к перемножению матриц больших размеров.
Скрипт для генерации матриц остался с предыдущих лабораторных работ. Для запуска программы надо указать аргументы
командной строки (Например: mpiexec -n 1 lab3.exe 800 matA.txt matB.txt)
