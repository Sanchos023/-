## Выводы

- Параллельная реализация демонстрирует **устойчивое снижение времени выполнения** при увеличении числа процессов для всех размеров матриц.

- Для больших размеров (N ≥ 800) наблюдается **почти линейное ускорение**.  
  Например, при N = 1600:
  - Ускорение ≈ 7.5  
  - Эффективность ≈ 94 %

- При увеличении размера матрицы в 2 раза время выполнения возрастает примерно в 8 раз, что подтверждает теоретическую сложность алгоритма **O(n³)**.

- Для малых размеров (N ≤ 400) влияние накладных расходов MPI более заметно, однако ускорение всё равно близко к линейному.

- Наибольший выигрыш от параллелизации достигается при больших размерах задачи, где доля вычислений существенно превышает затраты на коммуникацию.

- Реализация корректно масштабируется до 8 процессов и демонстрирует высокую вычислительную эффективность.
