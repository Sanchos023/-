# ✅ Вывод

1. Технология CUDA позволяет значительно ускорить умножение матриц.

2. На GPU Tesla T4 достигается производительность до **321 GFLOPS**.

3. Оптимальным размером блока является **32×32** (1024 потока) —
   это максимум потоков в блоке, что обеспечивает максимальное
   использование вычислительных ресурсов GPU.

4. Для малых матриц выигрыш от CUDA ограничен накладными расходами
   на передачу данных между CPU и GPU.

5. Для матриц 800×800 и больше CUDA демонстрирует
   высокую производительность и хорошую масштабируемость.

6. Наблюдается прямая зависимость производительности от
   конфигурации сетки блоков, что подтверждает важность
   правильного выбора block size.
